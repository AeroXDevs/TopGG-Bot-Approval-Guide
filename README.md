## About This Guide

This documentation was put together after analysing **1,000+ real rejection reasons** directly from the Top.gg official server's bot review channel. Every rule and every example in this guide comes from an actual reviewer decision — not guesses or assumptions.

If your bot got rejected and you don't know why, or you want to avoid rejection before submitting — read this.

---

## By The Numbers

| Stat | Count |
|------|-------|
| Total review embeds analysed | 979 |
| Bots approved | 328 |
| Bots declined | 594 |
| Unique rejection reasons found | 335+ |
| Approval rate | ~36% |

Only about 1 in 3 bots gets approved on first submission. This guide exists to put you in that group.

## Top 10 Most Common Rejection Reasons

| Rank | Reason | Times Seen |
|------|--------|-----------|
| 1 | Bot was offline during review | 99+ |
| 2 | Spam / AI-filled description on bot page | 56+ |
| 3 | Wrong prefix listed on bot page | 27+ |
| 4 | Bot went offline mid-review | 24+ |
| 5 | Wrong permissions in lock commands | 22+ |
| 6 | Most commands not working | 21+ |
| 7 | No help command or entry point | 17+ |
| 8 | Too few commands or features | 13+ |
| 9 | Bot owner banned from Top.gg server | 13+ |
| 10 | Core features locked behind premium | 7+ |
